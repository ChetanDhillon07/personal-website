## Overview

An experimental project management tool exploring new paradigms in drag-and-drop interfaces, heavily utilizing fluid animations for physical feedback.

## Features

- Physics-based card snapping and ordering.
- Dynamic color shifts based on item priority.
- Fast data synchronization using client-side caching.
