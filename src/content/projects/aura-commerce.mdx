## Overview

Aura Commerce is a headless e-commerce storefront designed for a boutique lifestyle brand, maximizing product visibility through an asymmetric grid and soft minimal aesthetic.

## Features

- Fast page loads using SSG and static optimization.
- Custom Shopify store synchronization.
- Asymmetric grid layouts highlighting core items.
